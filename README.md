# Mazharul Intelligence – React + Vite

    npm install
    npm run dev      # local dev server
    npm run build    # production build in /dist

- Content, prices and package scopes: `src/data.js` (edit here or load from a CMS).
- WhatsApp number: `WA` in `src/data.js`.
- Colours / layout: `src/index.css` (CSS variables at the top).
- Pages are switched with React state and the URL hash (`#pricing`), so it deploys to any static host without server rewrites.
